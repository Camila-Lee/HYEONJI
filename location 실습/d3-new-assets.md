## 1. 지방행정 인허가 데이터 (localdata.go.kr)

| 항목 | 내용 | 근거 |
|---|---|---|
| 기관 | 행정안전부 (담당부서 지역디지털협력과) | 확인: data.go.kr 후속 API 페이지의 제공기관 표기 |
| URL | https://www.localdata.go.kr/ → 접속 안 됨(연결 거부, 2026-11-13) | 확인 |
| 이전된 곳 | 공공데이터포털 https://www.data.go.kr/ (예: https://www.data.go.kr/data/15155033/openapi.do) | 확인: 경향신문 2026-01-25 "공공데이터 포털 한 곳으로 통합" |
| 기준일 | 통합 발표 2026-01-25 / API는 매일 갱신, 2일 전 기준 (빙상장업 API 수정일 2026-04-15) | 확인 |
| localdata 병행 운영 기한 | 2026-04-15까지 | 검색 요약 |
| 데이터 규모 | 인허가 195종 + 생활편의 14종 = 209종, 전부 API로 개방 | 확인: 경향신문 2026-01-25 |
| 형식 | 행정안전부 API: JSON·XML / 지자체 파일: CSV | 확인 |

**"동아리 활동"**
- **미확인.** 열어 본 페이지 어디에도 "동아리"라는 메뉴·게시판·업종이 없었고, 사이트 자체가 열리지 않아 메뉴를 직접 보지 못함.
- 비슷한 후보(체육 업종): 빙상장업(확인), 당구장업·체육도장업·체력단련장(검색 요약)
- 청소년 관련 업종: 미확인

**열 이름 → 뜻** (진주시 식품제조가공업 CSV 기준, 확인)

| 열 | 뜻 |
|---|---|
| 업종명 | 인허가 업종 (예: 식품제조가공업) |
| 인허가일자 | 영업 허가를 받은 날 |
| 영업상태명 | 영업 중 / 휴업 / 폐업 같은 현재 상태 |
| 업소명 | 가게 이름 |
| 소재지(도로명), 소재지(지번) | 주소 |
| 영업장면적 | 가게 넓이 |
| 우편번호(도로명) | 우편번호 |
| 업태명 | 세부 영업 형태 |
| 업소일련번호 | 가게 고유 번호 |

- 행정안전부 API의 응답 열 전체 목록: 미확인 (설명에 "인허가일자, 영업상태, 사업장명, 소재지주소 등"만 있음)

## 2. 한국관광 데이터랩 + 로컬 작업 폴더

| 항목 | 내용 | 근거 |
|---|---|---|
| 기관 | 한국관광공사 | 확인 |
| URL | https://datalab.visitkorea.or.kr/ · 지역별 관광 현황 …/loc/getAreaDataForm.do · 데이터 설명 …/getMetaInfoList.do | 확인 |
| 기준일 | 사람이 화면으로 직접 조회: 2026-11-12 (데이터 기간 2025-11~2026-10) / 서브에이전트 설명 페이지 조회: 2026-11-13 | 확인 |
| 숫자 다시 확인 | 수치는 화면에서 자바스크립트로 불러와서 서브에이전트가 다시 읽지 못함 → 2026-11-12 화면 기록만 근거 | 확인 |
| 이용 조건 | 수치는 추세용, 총량으로 쓰지 말 것 / 공식 다운로드 외 무단 수집 금지 | 확인 |
| 로컬 경로 | C:\Users\Administrator\Desktop\llm-local (데이터랩 숫자는 research/테마여행_트렌드.md 2-5절에 있음) | 확인 |

**지표 현황과 기준**

| 지표 | 데이터 출처 | 기준 | 세는 방법 |
|---|---|---|---|
| 방문자 수 | 이동통신 | 외지인 | 하루 단위, 여러 날 오면 날마다 따로 셈 |
| 숙박·체류시간 | 이동통신 | 외지인 | 한 달 단위, 연속 체류는 1명 |
| 관광소비 | 신용카드 | 내국인(현지인+외지인) | 카드 등록 주소로 현지인·외지인 구분 |
| 목적지 검색·인기관광지·맛집 | 내비게이션 | 현지인 / 외지인 / 전체 | 차량 이동 기준, 실제 방문자 수와 다를 수 있음 |
| 지역 데이터 범위 | - | - | 2020-01부터, 월간 조회는 최대 18개월 |

**용어(열) → 뜻** (데이터 설명 페이지, 확인)

| 용어 | 뜻 |
|---|---|
| 현지인 | 그 지자체에 살거나 일하거나 다니는 것으로 추정되는 사람 |
| 외지인 | 그 지자체에 상주하지 않는 사람 |
| 방문자 | 생활권을 벗어나 한 기지국에 30분 이상 머문 사람 |
| 숙박 방문자 | 23~08시에 같은 행정동에 누적 4시간 이상 머문 사람 |
| 외국인 | 연속 90일 이하로 머무는 외국인 (SKT) |
| 내비 검색건수 | 목적지를 검색하고 100m·1분 이상 이동한 경우 |

- 다운로드 파일의 실제 열 이름 목록: 미확인 (설명 페이지 일부만 읽음)
- 로그인 메뉴(마이 데이터랩 등): 로그인 필요로 미확인

## 3. 두 자산 비교

| 비교 항목 | 지방행정 인허가 데이터 | 한국관광 데이터랩 |
|---|---|---|
| 기관 | 행정안전부 | 한국관광공사 |
| 지금 받는 곳 | 공공데이터포털 (localdata.go.kr은 접속 안 됨) | datalab.visitkorea.or.kr |
| 단위 | 가게 1곳 = 1줄 | 지역(시·군·구) 단위 추세 |
| 형식 | CSV, API(JSON·XML) | 화면 조회 + 공식 다운로드 |
| 갱신 | 매일 (2일 전 기준) | 월 단위 |
| 열 뜻 확보 | CSV 열 이름 확인, API 열 목록은 미확인 | 용어 정의 확인, 다운로드 열 목록은 미확인 |
| 이용 주의 | 미확인 | 추세용, 총량 사용 금지, 무단 수집 금지 |
| 우리 서비스에 쓰는 곳 (해석) | 가게 카드의 주소·영업 중 여부 확인 | 테마 수요 근거, 기대효과 지표 |

**해석**: 둘은 겹치지 않고 서로 채워 줌. 데이터랩은 "어느 지역에 사람이 오는지", 인허가 데이터는 "그 지역의 가게가 지금도 영업 중인지"를 알려 줌.
